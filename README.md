# Plant Microbe Interaction Laboratory

A standalone, responsive laboratory website.

## Deploy with GitHub Pages

1. Create a GitHub repository (or open the repository where you want the site).
2. Upload `index.html` to the repository's **root** directory.
3. Commit the file to the branch you want to publish (commonly `main`).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the branch (for example, `main`) and the `/(root)` folder, then save.
7. Wait for GitHub Pages to finish deploying. The site URL will appear in the Pages settings.

## Notes

- The website is a single HTML file; its logo and site images are embedded, so no separate asset folder is required.
- Google Fonts are loaded from Google Fonts when a visitor has an internet connection. System-font fallbacks are included.
- The former in-app publishing controls are not part of the public GitHub Pages deployment workflow.
